# 佳明健康看板

通过 Garmin Connect 查询健康数据（心率、睡眠、步数、活动记录等）并生成分析报告。

**版本 1.0.0** —
- 🧠 **工具链调用（推荐）** — 注册为 LLM FunctionTool，大模型根据自然语言自动调用，支持灵活参数组合
- 🏛 **固定命令（兼容）** — 传统 `/xxx` 命令，习惯快捷操作的用户可继续使用

- 🔒 **安全提醒** — 本插件需要配置你的 Garmin 账号和密码（存储于插件配置中）。请优先在 **私聊（私信）** 环境中使用，避免在群聊中查询健康数据，以防个人运动信息和账号凭证泄漏。如果你在仅自己可用的私人 Bot 中使用群聊，请自行评估风险。

---

## 🧠 工具链调用（推荐方式）

插件注册了以下 11 个 FunctionTool，大模型会在对话中按需自动调用，无需记忆命令格式，像聊天一样查询即可。

### 💓 健康数据

| 工具 | 功能 | 自然语言示例 |
|------|------|-------------|
| `garmin_health_today` | 今日健康概览（心率+步数+睡眠） | 「我今天状态怎么样」「今天身体怎么样」 |
| `garmin_heart_rate` | 心率趋势（近7天） | 「最近心率怎么样」「我的心跳数据」 |
| `garmin_sleep` | 睡眠报告（近7天） | 「最近睡眠怎么样」「睡得好吗」 |
| `garmin_steps` | 步数数据（近7天） | 「最近走了多少步」「步数统计」 |
| `garmin_detailed_report` | 综合健康诊断报告（含7天平均和建议） | 「身体报告」「详细健康」「全面体检」 |

### 🏃 活动统计

| 工具 | 功能 | 自然语言示例 |
|------|------|-------------|
| `garmin_query_activities` | 查询活动记录，支持按日期范围、名称关键词、活动类型筛选 | 「最近的活动」「梧桐山」「昨天跑了什么」「看看我最近的徒步」「骑行记录」「游泳记录」 |
| `garmin_running_volume` | 跑量统计（自动区分路跑/越野跑） | 「这个月跑了多少」「跑量统计」「今年跑量」 |
| `garmin_activity_volume` | 通用活动量统计（徒步/步行/骑行/游泳等） | 「今年徒步多少」「这个月骑行多少」「最近游泳统计」 |
| `garmin_personal_best` | 个人最佳记录（最长距离/最快配速/最大爬升/最长时长） | 「我的PB」「最佳成绩」「跑得最好的一次」 |
| `garmin_yearly_report` | 年度运动报告（活动次数、总距离、总时长、总爬升、月度分布） | 「年度报告」「2025年运动总结」 |
| `garmin_rename_activity` | 修改Garmin活动名称（需要确认后执行） | 「把梧桐山改成梅沙尖」「改活动名」 |

### 工具链使用说明

- **无需记忆**：所有工具由大模型自动识别意图并调用，你只需要正常说话
- **参数灵活**：`garmin_query_activities` 支持活动类型筛选（`running`/`hiking`/`walking`/`cycling`/`swimming`/`trail_running`）、日期范围、关键词搜索自由组合
- **跑量区分**：`garmin_running_volume` 会自动区分路跑（Running）和越野跑（Trail Running），无需手动标注
- **通用统计**：`garmin_activity_volume` 可统计徒步、步行、骑行、游泳等非跑步活动
- **查询即问即答**：工具调用结果会直接输出到对话中，等待片刻即可

## 🏛 固定命令（兼容方式）

如果你习惯传统命令操作，以下命令仍然可用。工具链和固定命令可同时使用，互不冲突。

### 📊 健康数据

| 命令 | 功能 |
|------|------|
| `/健康` | 今日健康概览（心率+步数+睡眠） |
| `/心率` | 最近7天心率趋势 |
| `/睡眠` | 最近7天睡眠报告 |
| `/步数` | 最近7天步数数据 |
| `/身体报告` | 详细健康诊断报告（含7天平均和建议） |

### 🏃 活动统计

| 命令 | 功能 |
|------|------|
| `/活动` | 查看活动概览（默认最近5条） |
| `/活动 N` | 自定义拉取最近 N 条（按配置分页拉取）。注意：4 位纯数字会优先按年份解析，例如 `/活动 2026` 表示查询 2026 全年；如需最近 N 条，请使用非 4 位数字，例如 `/活动 10` |
| `/活动 日期` | 按日期查询（支持格式：`2026` 全年 / `2026-06` 整月 / `2026年6月` 中文月 / `2026-06-08` 单日 / `2026年6月8日` 中文单日 / `2026/06/08` 斜杠单日）。解析优先级：无参默认最近5条 → 4位年份 → 其他纯数字N条 → 月/日日期 → 活动名关键词 |
| `/活动 活动名` | 按活动名模糊搜索 |
| `/跑量 [参数]` | 跑量统计（区分路跑和越野跑），参数支持：`all` 全部 / `2026` 全年 / `2026-06` 整月 / `2026-06-08` 单日 / `2026年6月` 中文月 / `2026年6月8日` 中文单日 / `2026/06/08` 斜杠单日 / `30` 近 N 天 |
| `/PB` | 个人最佳记录（最长距离/最快配速/最大爬升/最长时长），大小写均可 |
| `/年度报告 [年份]` | 年度运动报告（默认今年），如 `/年度报告 2025` |
| `/游泳 [参数]` | 游泳统计，参数规则同 `/跑量` |
| `/徒步 [参数]` | 徒步统计，参数规则同 `/跑量` |
| `/步行 [参数]` | 步行统计，参数规则同 `/跑量` |
| `/骑行 [参数]` | 骑行统计，参数规则同 `/跑量` |

## 配置

在 AstrBot WebUI 插件配置中填写：

| 配置项 | 说明 |
|--------|------|
| `garmin_email` | Garmin Connect 登录邮箱 |
| `garmin_password` | Garmin Connect 登录密码 |
| `garmin_is_cn` | 是否为 Garmin 中国区账号（布尔值，默认 `true`） |
| `garmin_max_activities` | 活动分页拉取上限，默认 `600`，通常足够覆盖近几年记录；活动很多或需要统计更早年份可调大，最大建议 `10000`，但查询会更慢 |

支持 Session 持久化，只需配置一次，后续自动保持登录状态。

## 依赖

- `garminconnect>=0.3.3`

## 安装

1. 在 AstrBot 插件市场搜索 `佳明健康看板`
2. 或手动将本插件目录放入 `data/plugins/` 下
3. 在 WebUI 中配置 Garmin 账号密码
4. 重启 AstrBot 即可使用

## 注意事项

- 中国区账号请将 `garmin_is_cn` 设为 `true`，国际区账号设为 `false`
- Session 文件保存在插件目录下的 `.garmin_session` 文件夹中
- 工具链自动注册后，大模型会在对话中按需调用，无需手动输入命令
- 固定命令和工具链可同时使用，互不冲突
- 🧠 **推荐优先使用自然语言查询**，更直观、更灵活
- 🔒 **安全提示**：插件需配置 Garmin 账号密码，建议仅在私聊中使用。如需在群聊中使用，请确保 Bot 仅对你个人可用，避免他人触发查询导致个人信息泄漏
