## 🚀 两种使用方式

| 方式 | 说明 |
|:---|:---|
| 🧠 **工具链调用（推荐）** | 注册为 LLM FunctionTool，大模型根据自然语言自动调用，支持灵活参数组合 |
| 🏛 **固定命令（兼容）** | 传统 `/xxx` 命令，习惯快捷操作的用户可继续使用 |

> 🔒 **安全提醒**：本插件需要配置你的 Garmin 账号和密码（存储于插件配置中）。请优先在 **私聊（私信）** 环境中使用，避免在群聊中查询健康数据，以防个人运动信息和账号凭证泄漏。如果你在仅自己可用的私人 Bot 中使用群聊，请自行评估风险。

## 🧠 工具链调用（推荐方式）

插件注册了以下 11 个 FunctionTool，大模型会在对话中按需自动调用，无需记忆命令格式，像聊天一样查询即可。

### 💓 健康数据

| 工具 | 功能 | 自然语言示例 |
|:---|:---|:---|
| `garmin_health_today` | 今日健康概览（心率+步数+睡眠） | 「我今天状态怎么样」「今天身体怎么样」 |
| `garmin_heart_rate` | 心率趋势（近7天） | 「最近心率怎么样」「我的心跳数据」 |
| `garmin_sleep` | 睡眠报告（近7天） | 「最近睡眠怎么样」「睡得好吗」 |
| `garmin_steps` | 步数数据（近7天） | 「最近走了多少步」「步数统计」 |
| `garmin_detailed_report` | 综合健康诊断报告（含7天平均和健康建议） | 「报告」「身体报告」「健康报告」 |

### 🏃 活动统计

| 工具 | 功能 | 自然语言示例 |
|:---|:---|:---|
| `garmin_query_activities` | 查询活动记录，支持按日期范围、名称关键词、活动类型筛选 | 「最近的活动」「梧桐山」「昨天跑了什么」「看看我最近的徒步」「骑行记录」「游泳记录」 |
| `garmin_running_volume` | 跑步统计（自动九类细分：跑步/路跑/场地跑/室内跑/跑步机/虚拟跑/越野跑/超马/障碍跑） | 「这个月跑了多少」「跑量统计」「今年跑量」 |
| `garmin_activity_volume` | 通用活动量统计（徒步/步行/骑行/游泳等） | 「今年徒步多少」「这个月骑行多少」「最近游泳统计」 |
| `garmin_personal_best` | 个人最佳记录（最长距离/最快配速/最大爬升/最长时长） | 「我的PB」「最佳成绩」「跑得最好的一次」 |
| `garmin_yearly_report` | 年度运动报告（活动次数、总距离、总时长、总爬升、月度分布） | 「年度报告」「2025年运动总结」 |
| `garmin_rename_activity` | 修改Garmin活动名称（需要确认后执行） | 「把梧桐山改成梅沙尖」「改活动名」 |

### 📝 工具链使用说明

- **无需记忆**：所有工具由大模型自动识别意图并调用，你只需要正常说话
- **参数灵活**：`garmin_query_activities` 支持活动类型筛选（`running`/`hiking`/`walking`/`cycling`/`swimming`/`trail_running`）、日期范围、关键词搜索自由组合
- **跑步区分**：`garmin_running_volume` 会自动九类细分——跑步（Running）、路跑（Street Running）、场地跑（Track Running）、室内跑（Indoor Running）、跑步机（Treadmill Running）、虚拟跑（Virtual Running）、越野跑（Trail Running）、超马（Ultra Running）和障碍跑（Obstacle Racing），无需手动标注
- **游泳区分**：`/游泳` 命令会自动三分类细分——游泳（Swimming）通用记录、泳池游泳（Lap Swimming）和公开水域（Open Water Swimming），无需手动标注
- **通用统计**：`garmin_activity_volume` 可统计徒步、步行、骑行、游泳等非跑步活动
- **行走拆解**：徒步分徒步+负重徒步（二分类），步行分步行+散步+竞走（三分类）
- **骑行拆解**：骑行17类细分（下坡山地骑行/躺车骑行/越野骑行/虚拟骑行/碎石未铺路骑行/电助力山地车/电动自行车骑行/手轮车/山地骑行/小轮车/室内骑行/室内手轮车/场地骑行/公路骑行/Enduro骑山地车/eEnduro山地骑行/骑行），各 typeKey 独立统计
- **查询即问即答**：工具调用结果会直接输出到对话中，等待片刻即可

## 🏛 固定命令（兼容方式）

如果你习惯传统命令操作，以下命令仍然可用。工具链和固定命令可同时使用，互不冲突。

### 📊 健康数据

| 命令 | 功能 |
|:---|:---|
| `/健康` | 今日健康概览（心率+步数+睡眠） |
| `/心率` | 最近7天心率趋势 |
| `/睡眠` | 最近7天睡眠报告 |
| `/步数` | 最近7天步数数据 |
| `/报告` | 详细健康诊断报告（含7天平均和AI健康建议）|

### 🏃 活动统计

|:---|:---|
| `/活动` | 查看活动概览（默认最近5条） |

| `/步行 [参数]` | 步行统计（步行+散步+竞走，三分类），参数规则同 `/跑步` |

## ⚙️ 配置

在 AstrBot WebUI 插件配置中填写：

| 配置项 | 说明 |
|:---|:---|
| `garmin_email` | Garmin Connect 登录邮箱 |
| `garmin_password` | Garmin Connect 登录密码 |
| `garmin_is_cn` | 中国区账号（默认 `true`） |
| `garmin_max_activities` | 活动分页上限（默认 `600`，最大 `10000`） |
| `health_ai_provider` | **[健康建议] 使用的 AI 模型**。选择一个 AI 模型来生成个性化健康小贴士。留空则使用内置规则判断。 |
| `health_ai_prompt_template` | **[健康建议] 提示词模板**。发送给 AI 的提示词模板。用 `{health_data}` 占位符嵌入健康数据，留空使用内置默认模板。 |

支持 Session 持久化，配置一次后自动保持登录。

## 📋 依赖

- `garminconnect>=0.3.4`

## 📦 安装

1. AstrBot 插件市场搜索 `佳明健康看板`
2. 或手动放入 `data/plugins/` 目录
3. WebUI 配置账号密码
4. 重启 AstrBot

## ⚠️ 注意事项

- 中国区账号 `garmin_is_cn=true`，国际区 `false`
- Session 存于 `.garmin_session` 文件夹
- 工具链与固定命令可同时使用，互不冲突
- 🧠 推荐优先使用自然语言查询
- 🔒 建议仅私聊使用；群聊请确保 Bot 仅个人可用
